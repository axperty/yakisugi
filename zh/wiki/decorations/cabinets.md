# Cabinets for Farmer's Delight

This mod adds compatibility for [Farmer's Delight](https://github.com/vectorwing/FarmersDelight/wiki) by added cabinets made from [charred planks](/wiki/getting-started/charred-planks) and slightly charred planks. It allows the player to store resources inside.
To craft them, follow these steps:

1. Obtain charred planks or slightly charred trapdoors and slabs.
2. Place the items on the [crafting table](https://minecraft.wiki/w/Crafting_Table) grid like this:

<img src="/assets/recipes/charred_cabinet_recipe.gif">

*Texture created by Axperty.*

::: tip Important
You need to have [Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight) installed along with Yakisugi for charred and slightly charred cabinets to be enabled.
:::
